## Build dependency

`libnymea-sunspec-dev` (package from `repos.nymea.io`, 1.15.2). `sunspec.pri`
resolves it through `pkg-config nymea-sunspec`.

## Absolute rule

**`libnymea-sunspec` is NOT vendored and must not be.** The plugin must
stay rebasable on upstream nymea: every change lives in `sunspec/`.
If a change to the library seems unavoidable, stop and raise the
question rather than modifying it.

## Commit hygiene

Two kinds of changes, never to be mixed in the same commit:

- **upstream fixes** (bugs present in nymea 1.15.2 — AC-1 to AC-4 of the
  spec): message in English, no reference to ETM / Fronius / PowerSync, so
  they remain proposable upstream;
- **ETM-specific** (`fronius` vendor, product settings): separate commits.

## EXIT

If nymea integrates upstream the AC-1..AC-4 fixes and an equivalent Fronius
vendor: rebase on the upstream version and reduce this directory to the ETM delta.
